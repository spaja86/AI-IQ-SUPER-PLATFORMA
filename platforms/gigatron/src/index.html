O Platformi

GIGATRON je integraciona tačka za IT/elektroniku procurement, affiliate/partner prodaju i B2B supply chain u okviru AI IQ SUPER PLATFORMA ekosistema. Gigatron je najveći srpski elektronski maloprodajni lanac u regionu.

Usluge

  • 🔍 IT i elektronika katalog — pretraga, filtriranje, SKU upravljanje
  • 📦 B2B nabavka — narudžbine, dobavljači, ugovori
  • 🤝 Affiliate / Partner program — provizije, tracking, isplate
  • 📊 Upravljanje zalihama — dostupnost u realnom vremenu

API Endpoints

  • GET /api/gigatron/health — Health check

  • GET /api/gigatron/order/[id] — Status narudžbine
  • POST /api/gigatron/affiliate/track — Affiliate event
  • GET /api/gigatron/inventory — Stanje zaliha
