# Nova Generacija Platform

> Konsolidovana platforma nove generacije — unifikuje sve postojeće platforme pod jednim interfejsom i proširuje industrijsku mrežu na EU i međunarodne tržišta.

## Uloga

`platforms/nova-generacija/` je gateway surface koji:

- Unifikuje `platforms/io-openui-ao/`, `platforms/menjacnica/`, `platforms/kompanija-spaja/`, `platforms/poslovni-novcanik/`, `platforms/world-bank/` pod jednim koordinacionim slojem
- Proširuje industrijsku mrežu ka EU/međunarodnom tržištu
- Implementira Nova Generacija supplier i procurement API
- Koordinira automatski compliance monitoring
- Sinhronizuje sa `spaja86/IO-OPENUI-AO` i budućim linked repo-jima

## Tehnološki Stack

- **Runtime:** Next.js 16+ (App Router)
- **AI Engine:** SpajaPro 16 Hipermreza (16×16, 256 čvorova)
- **OMEGA AI:** 50 persona u 16 oktava
- **Auth:** SpajaUltraOmegaCore ΩAuth
- **DB:** Supabase + Vercel KV
- **Blockchain:** Polygon (pametni ugovori)
- **Mobilna Mreža:** 16 centrala (1873G)
- **Finansije:** AI IQ World Bank + Menjačnica + Stripe
