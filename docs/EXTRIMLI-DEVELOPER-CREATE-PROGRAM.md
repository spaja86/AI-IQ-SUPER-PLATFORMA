  - manji obim: niži prag otpora i brža validacija,
  - srednji obim: pojačan review + governance gate,
  - veći obim: puna WAWE/audit disciplina pre promocije.

  - `SINEMETRIČKO` (narativ/signal),

  - tehnički readiness signal,
