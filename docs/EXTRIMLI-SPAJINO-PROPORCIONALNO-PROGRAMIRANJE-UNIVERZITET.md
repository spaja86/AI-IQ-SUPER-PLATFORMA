# EXTRIMLI — SPAJINO PROPORCIONALNO PROGRAMIRANJE UNIVERZITET

## Purpose

Ovaj dokument zaključava značenje i governance model za **SPAJINO PROPORCIONALNO PROGRAMIRANJE UNIVERZITET** kao additive-only univerzitetski interpretativni sloj iznad postojećeg `PROPORCIONALNO PROGRAMIRANJE` track-a.

## Source-of-truth surfaces

- Technical signal: `/api/extrimli/extrem`
- Governance orchestration: `/api/extrimli/extrondol`
- Public-safe boundary: `/api/extrimli/spaja-kod`

## Canonical vocabulary and spelling lock

- Canonical term ostaje tačno `SPAJINO PROPORCIONALNO PROGRAMIRANJE UNIVERZITET`.
- Canonical narrative title ostaje tačno `Spreg funkcionalnog i objektno programiranja sa mnoštvo novih petlji`.
- Ovaj sloj ostaje drugi kanonski stub bounded paketa `DEVELOPER AND CREATE == VRH PROGRAMSKOG EKVILADENTA == SMART PROGRAMSKI JEZIK`: `funkcionalni tok`, `objektna struktura` i `petlje/proporcionalna ravnoteža` ostaju tehnički dokaz da je jezik funkcionalan u objektnom okruženju, bez novog runtime subsistema i bez novog source-of-truth sistema.
- `funkcionalni tok` = `profileInput.functionalFlowPercent`
- `objektna struktura` = `profileInput.objectStructurePercent`
- `petlje orkestracija i proporcionalna ravnoteža` = `profileInput.petljeOrchestrationBalancePercent`
- Readiness posture ostaje zaključan na `READY`, `WATCH`, `BLOCKED`.

## Additive boundary

- Ovo nije nova paralelna platforma i ne menja postojeći `PROPORCIONALNO PROGRAMIRANJE` contract.
- Track ostaje additive pod-track iznad postojećeg proporcionalnog sloja.
- `PROTKROV FUNKCIJA`, `OBJEKTNE PARADOKSALNE ETAPE` i ostali postojeći termini ostaju netaknuti.
- Nema nove javne rute; postojeće `/api/extrimli/extrem`, `/api/extrimli/extrondol` i `/api/extrimli/spaja-kod` surface granice ostaju zaključane.

## PETLJE coupling

- „Mnoštvo novih petlji“ se dokazuje isključivo kroz postojeći `EXTRIMLI EXTRONDOL EXTREM PETLJE` ugovor.
- Univerzitetski track koristi postojeće kanonske PETLJE readiness/conflict/freeze rezultate kao tehnički dokaz nastavnog obima.
- Nema posebnog loop sistema, duplog kataloga ili paralelnog signalnog modela.

## Ownership split

- **EXTREM** objavljuje tehnički univerzitetski signal izveden iz postojećeg proporcionalnog track-a, funkcionalnih track-ova, objektnih track-ova i PETLJE dokaza.
- **EXTRONDOL** propagira signal u WAWE 1–5, promotion freeze, release audit summary, rollback, downstream reference i human-review zahteve.
- **SPAJA KOD** ostaje public-safe summary boundary i ne izlaže sirove formule, interne težine ni detalje pojedinačnih petlji.

## WAWE impact

1. **WAWE-1** — termin, naslov, scope lock i additive-parent odnos moraju ostati eksplicitni.
2. **WAWE-2** — funkcionalni tok, objektna struktura i PETLJE orkestracija ostaju najmanje u WATCH posturi.
3. **WAWE-3** — PETLJE evidence, proporcionalni parent track i audit razlozi moraju biti vidljivi kroz EXTRONDOL governance.
4. **WAWE-4** — produkciona promocija zahteva READY ili eksplicitno odobren WATCH bez skrivenih proporcionalnih ili PETLJE blockera.
5. **WAWE-5** — post-release resilience zadržava rollback, downstream reference i human-review obaveze za ovaj track.

## Compatibility rules

- Proširenje ostaje additive-only kroz docs, types, tests i postojeći route payload.
- `PROPORCIONALNO PROGRAMIRANJE` ostaje parent track i source contract.
- Downstream consumer-i sinhronizuju samo audit-safe readiness/governance polja.
