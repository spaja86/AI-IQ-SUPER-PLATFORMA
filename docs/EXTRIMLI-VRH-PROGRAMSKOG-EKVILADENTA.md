# EXTRIMLI — VRH PROGRAMSKOG EKVILADENTA

## Purpose

`VRH PROGRAMSKOG EKVILADENTA` zaključava additive-only interpretativni vršni sloj iznad postojećeg parent track-a `PROPORCIONALNO PROGRAMIRANJE`.

- nema novih runtime ruta
- nema paralelnog source-of-truth sistema
- oslonac ostaju `/api/extrimli/extrem`, `/api/extrimli/extrondol` i `/api/extrimli/spaja-kod`

## Parent relation

- Parent track: `PROPORCIONALNO PROGRAMIRANJE`
- Contract mode: additive-only parented layer
- Model: interpretativni orkestracioni/governance narativ nad postojećim EXTRIMLI i AI IQ slojevima

`VRH PROGRAMSKOG EKVILADENTA` nije novi modul, već vršni plan koji orkestrira postojeće proporcionalne, metričke, sinemetričke, paradijogonalne i AI-IQ jezičke slojeve u jednu governance priču.

## Ownership split

- **EXTREM** nosi tehnički signal, metrike, readiness/conflict i `DOK + DIK + FOR`
- **EXTRONDOL** nosi WAWE, freeze/promotion, audit, rollback i `DAK + DUK`
- **SPAJA KOD** prikazuje samo audit-safe zbirni status bez sirovih formula

Ovaj ownership split ostaje isti kao kod parent i sibling track-ova i ne uvodi novi governance izvor.

- Nema novih source-of-truth ruta.

- Buduća realizacija, ako bude potrebna, sme ići samo kao additive proširenje u:
  - EXTREM tehničkom izveštaju
  - EXTRONDOL governance i `releaseAuditSummary`
  - SPAJA KOD summary statusu
  - pratećoj dokumentaciji i testovima

## Validation criteria

- dozvoljeni statusi ostaju `READY | WATCH | BLOCKED`
- obavezan fallback za `NaN`, `Infinity`, prazne ili konfliktne ulaze
- javni izlaz ostaje audit-safe i ne izlaže interne formule
- ownership split `DOK + DIK + FOR` naspram `DAK + DUK` mora ostati nepromenjen
