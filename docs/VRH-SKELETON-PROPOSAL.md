## Contract and safety
A skeleton has bounded nodes with named input/output types and directed links with evidence IDs. Reject malformed values, duplicate nodes/links, incompatible types, absent/unverified evidence, cycles and empty links. External registry supplies verified evidence IDs; the validator does NOT establish evidence integrity, freshness or authority. Production registry and permission checks are deferred.
Valid proposal yields REVIEW_REQUIRED, never execution enabled. No shell, eval, network, payment, file writes, production changes or automatic authorization. Unknown and failed conditions block. Standalone dry-run does not amend the existing no-new-runtime route/engine contracts.
