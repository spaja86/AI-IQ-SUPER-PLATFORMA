# PROGRAMSKI JEZIK PO PROSPARITETU DEKLASIRANE MATRICE U EKSTAZI

## Svrha

`PROGRAMSKI JEZIK PO PROSPARITETU DEKLASIRANE MATRICE U EKSTAZI (PREDISPOZIJA EKSTREMNIH GLASOVNIH KOMANDI U ETAPSIKM SENZACIJAMA)` uvodi additive-only EXTRIMLI profil za prosparitetno tumačenje deklasiranih matrica bez uvođenja nove source-of-truth rute.

## Ownership split

- `DOK + DIK + FOR` = EXTREM tehnički signal
- `DAK + DUK` = EXTRONDOL governance odluka
- `SPAJA KOD` = samo audit-safe završni status
- `PROSPARITET` = repo-local input-domain-only interpretacioni domen

## Tehnički signal (EXTREM)

EXTREM zaključava bounded metrike:

- `deklasiraneMatriceReadinessScore`
- `prosparitetAlignmentScore`
- `glasovneKomandePredispozicijaScore`
- `etapsikmSenzacijeStageCohesionScore`
- `driftConflictScore`
- `continuationReadinessScore`

Dozvoljene status klase ostaju `READY | WATCH | BLOCKED`.

## Governance mapiranje (EXTRONDOL)

EXTRONDOL prevodi EXTREM signal u audit-safe governance izlaz:

- `WAWE` progression
- `promotionFreeze`
- `humanReviewRequired`
- `rollbackPlanRequired`
- `releaseAuditSummary`
- downstream reference prema `spaja86/IO-OPENUI-AO`

Raw tehnički detalji ne izlaze van EXTREM + EXTRONDOL slojeva; javni izlaz ostaje audit-safe summary.

## AI IQ PROGRAMSKI JEZIK integracija

- Novi track ostaje u `EXTRIMLI-EXTRONDOL-EXTREM` profilu.
- Signal mapping stoji uz `FOR`, `PROGRAMSKI JEZIK INFORMACIONIH TOKOVA`, `PRETPOSTAVKA` i gaming profile.
- Explainability razlozi ostaju deterministički i additive-only.
- Konsolidovani status ulazi u `dokDikDakDukConsistencyHealth`.

## Fallback i edge cases

Deterministic fallback je obavezan za:

- `NaN`
- `Infinity`
- prazne ili nevalidne signale
- nevalidne sekvence
- out-of-range procente
- drift/conflict eskalaciju ili invalid FOR sekvencijalnu konfiguraciju koja aktivira deterministic fallback

## Runtime boundary

- Nema nove javne runtime rute.
- Postojeći surface-ovi ostaju `/api/extrimli/extrem`, `/api/extrimli/extrondol` i additive AI IQ summary sloj.
